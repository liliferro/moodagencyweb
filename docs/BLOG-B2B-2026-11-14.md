# Publicación de guías B2B

Fecha editorial: 14 de noviembre de 2026 (Ciudad de México).

12 URLs nuevas y ampliación de /blog/automatizar-seguimiento-comercial/. Se conserva el contenido previo de seguimiento y su fecha de publicación. El blog contiene 18 guías; el sitemap, 44 páginas indexables.

## Fuente y reconstrucción

Contenido editable: src/articles.json. Los 13 artículos de esta entrega tienen b2b=true, fecha, metadatos y portada individual. Cada imagen es una ilustración editorial generada con IA, no evidencia de un cliente.

Reconstrucción completa: python src/build.py (requiere Pillow y Node.js). El paso final ejecuta src/publish-b2b.mjs para conservar las fechas, portadas, metadatos y enlaces de la serie. Para regenerar solamente la serie sobre el sitio existente: node src/publish-b2b.mjs.

## Comprobaciones realizadas antes de publicar

- Un H1 por artículo y canonical absoluto individual.
- Título y descripción propios, Open Graph y Twitter con portada y texto alternativo.
- Article, WebPage, Organization, WebSite, ImageObject y BreadcrumbList coherentes con el contenido.
- Enlaces internos contrastados con el inventario de rutas; cada artículo aparece una vez en blog y sitemap.
- Tablas con cabeceras y contenedor horizontal para pantallas estrechas.
- Conservación del contenido anterior del artículo de seguimiento.
- Retiro de notas editoriales, ejemplos no documentados y promesas de resultados.
- Las variables entre corchetes en prompts y ejemplos son campos intencionales para completar.

## Exactitud editorial

DENUE registra establecimientos, no intención de compra. Cifra de mayo de 2026 contrastada con INEGI. Las recomendaciones sobre ChatGPT Search se contrastaron con OpenAI; las de funciones de IA de Google, con Search Central. No se equipara una mención con una venta ni se garantiza indexación, posicionamiento o citas. La fórmula ROMI usa margen de contribución y costo total de marketing, con atribución y cohorte explícitas.

## Límites de la revisión

La comprobación de código no prueba la indexación real ni la visibilidad en respuestas de IA. No se declara aprobación de Core Web Vitals, una puntuación de PageSpeed ni una auditoría WCAG completa. Las portadas PNG requieren medición de peso y rendimiento en producción; se recomienda generar variantes WebP o AVIF cuando esté disponible el entorno de imágenes. La revisión HTTP posterior debe confirmar el despliegue y la carga de cada recurso.
